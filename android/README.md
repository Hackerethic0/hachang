# แอป Android (WebView) สำหรับทดสอบ

แอปนี้ห่อหน้าเว็บ "หาช่าง" ที่รันบนคอมพิวเตอร์ของคุณ (ต้องเปิด `start-phone.bat` ค้างไว้)

## สร้างไฟล์ APK
1. ติดตั้ง Android Studio (รุ่นล่าสุด) แล้วเลือก Open > โฟลเดอร์ `android`
2. รอ Gradle Sync (ต้องต่ออินเทอร์เน็ตครั้งแรก)
3. ต่อมือถือ (เปิด USB debugging) แล้วกด Run หรือเลือก Build > Build APK(s) แล้วส่งไฟล์ไปติดตั้ง
4. เปิดแอปครั้งแรก ใส่ที่อยู่เซิร์ฟเวอร์:
   - มือถือจริง: `http://IP-ของคอมพิวเตอร์:3000` (ดูจากหน้าต่างที่รัน `start-phone.bat`; มือถือและคอมพิวเตอร์ต้องอยู่ Wi-Fi เดียวกัน)
   - อีมูเลเตอร์: `http://10.0.2.2:3000`

เปลี่ยนที่อยู่ภายหลังได้จากหน้า "เชื่อมต่อเซิร์ฟเวอร์ไม่ได้" > เปลี่ยนที่อยู่เซิร์ฟเวอร์

หมายเหตุ: เวอร์ชันนี้อนุญาต http เพื่อทดสอบเท่านั้น ก่อนขึ้นระบบจริงให้ใช้ HTTPS และลบ `network_security_config.xml`
หน้าเว็บใช้ไลบรารีในเครื่อง (public/vendor) จึงไม่ต้องใช้อินเทอร์เน็ตบนมือถือ แค่ต่อ Wi-Fi เดียวกับคอมพิวเตอร์

## การโทรในแอป (WebRTC)
- แอปขอสิทธิ์ไมโครโฟนเมื่อรับสาย และปุ่ม "ลำโพง" ในหน้าจอโทรสลับลำโพง/หูฟังได้จริงผ่าน `AndroidBridge.setSpeaker`
- การโทรต้องใช้ **HTTPS หรือ localhost** (เบราว์เซอร์/WebView ไม่ยอมให้ใช้ไมค์บน http://192.168.x.x)
  - ทดสอบด้วยสาย USB: `adb reverse tcp:3000 tcp:3000` แล้วตั้งที่อยู่เซิร์ฟเวอร์ในแอปเป็น `http://localhost:3000`
  - ใช้งานจริง: วางหลัง reverse proxy ที่มี HTTPS (เช่น Caddy/Nginx) และควรตั้ง TURN server ผ่านตัวแปร `ICE_SERVERS`
