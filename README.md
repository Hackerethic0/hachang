# หาช่าง - หางานช่าง

## เริ่มใช้งานเร็วที่สุด (ไม่ต้องติดตั้งฐานข้อมูล / ไม่ต้อง npm install)
ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 22.13 ขึ้นไป (เลือกตัว LTS)

- **Windows:** ดับเบิลคลิก `start.bat` ถ้าเครื่องยังไม่มี Node.js โปรแกรมจะถามว่าให้ดาวน์โหลดเวอร์ชันพกพา (~30MB) มาไว้ในโฟลเดอร์ `runtime/` ให้ไหม ไม่ต้องติดตั้งลงเครื่อง ไม่ต้องใช้สิทธิ์ผู้ดูแล และตรวจสอบไฟล์ด้วย SHA256 จาก nodejs.org ก่อนใช้
- **macOS / Linux:** `./start.sh`
- หรือสั่งเอง: `node server-lite.js` แล้วเปิด http://localhost:3000

ถ้าเปิดไม่ได้: แตกไฟล์ `hachang.zip` ทับ "ทั้งโฟลเดอร์" (ต้องมี `server-lite.js`, `public/` และ `public/media/` ตรงรุ่นเดียวกัน) แล้วปิดหน้าต่างดำเดิม เปิด `start.bat` ใหม่

ครั้งแรกระบบสร้างฐานข้อมูล `hachang.db` และข้อมูลตัวอย่างให้เอง
บัญชีตัวอย่าง: `customer@demo.th`, `tech@demo.th` (รหัส `1234`)
ผู้ดูแลระบบ: หน้าเข้าสู่ระบบไม่แสดงตัวเลือกนี้ ให้เปิด `http://localhost:3000/#admin` แล้วเข้าด้วย `admin@demo.th` / `admin` (ซ่อนจากหน้าจอเท่านั้น ไม่ใช่การรักษาความปลอดภัย ต้องเปลี่ยนรหัสผ่านก่อนใช้งานจริง)

ทดสอบระบบ: `node test-lite.js` (38 ข้อ: เครดิต กันโกง กันช่องทางติดต่อ สลิป สิทธิ์ข้อมูล)

### ปรับการหักเครดิต (หลังบ้าน)
เข้าด้วย `admin@demo.th` > แท็บ **งาน/ช่าง** > ช่อง "อัตรา %" ของแต่ละงาน (ว่าง = ใช้ค่ามาตรฐาน) มีผลทันทีกับช่างที่กดรับงานนั้นต่อจากนี้
ค่ามาตรฐาน ขั้นต่ำ ต้นทุน ระยะกันโกง และคอมมิชชัน อยู่ที่แท็บ **ตั้งค่า**

### เปิดให้เครื่องอื่นในเครือข่ายใช้ด้วย
ค่าเริ่มต้นเปิดเฉพาะเครื่องนี้ (127.0.0.1) หากตั้ง `HOST=0.0.0.0` ควรใช้หลังไฟร์วอลล์/HTTPS และตั้ง `DEMO_MODE=0`

## เวอร์ชัน production: Express + PostgreSQL

Node.js + Express + PostgreSQL backend และหน้าเว็บ React + Tailwind (ไฟล์เดียว) ที่ต่อ API จริง

## รัน
```bash
cp .env.example .env        # แก้ DATABASE_URL, JWT_SECRET
npm install
export $(cat .env | xargs)
npm run db:init             # สร้างตารางจาก schema.sql
npm run db:seed             # ข้อมูลตัวอย่าง
npm start                   # เปิด http://localhost:3000
```
บัญชีตัวอย่าง: `customer@demo.th`, `tech@demo.th` (รหัส `1234`), `admin@demo.th` (รหัส `admin`)

## โครงสร้าง
- `server-lite.js` เวอร์ชันพร้อมรัน (SQLite ในตัว ไม่มี dependency) API เดียวกับ server.js
- `test-lite.js` ชุดทดสอบ end-to-end
- `public/media/` วิดีโอพื้นหลังหน้าเข้าสู่ระบบ 4 คลิป (แอนิเมชัน 8 วินาที ใส่วิดีโอจริงทับได้ ดู `public/media/README.txt`) และ `tools/make-videos.js` ตัวสร้างคลิป
- `schema.sql` ฐานข้อมูล PostgreSQL
- `server.js` API (auth, jobs, หักเครดิตใน transaction, สลิป, tracking, รีวิว, รายงาน, Affiliate, admin, `/api/state`)
- `public/index.html` หน้าเว็บ (ดึงสถานะจาก `/api/state` ทุก 4 วินาที)
- `seed.js` ข้อมูลตัวอย่าง

## กลไกสำคัญ
- **หักเครดิต**: `POST /api/jobs/:id/accept` ล็อกแถวงานและช่าง (`FOR UPDATE`) แล้วหักเครดิต บันทึก ledger และ log ใน transaction เดียว รับซ้ำไม่ได้ (UNIQUE job_id+tech_id)
- **อัตราหัก**: ต่องาน (`jobs.fee_rate`) แล้วจึงใช้ค่ามาตรฐาน (`settings.fee_rate_pct`); ขั้นต่ำ `min_fee`
- **กันโกง**: บล็อกเมื่ออุปกรณ์ช่างตรงกับลูกค้า หรือตำแหน่งช่างห่างงานเกิน `max_distance_km`; เฝ้าระวัง (warn) เมื่อเกิน 60%
- **กันช่องทางติดต่อ**: `noContact()` ที่ server (ตรวจซ้ำจากฝั่ง client) ลูกค้า/ช่างเห็นเบอร์กันหลังรับงานเท่านั้น
- **สิทธิ์ข้อมูล**: ช่างเห็นงานเปิดเมื่อเครดิต > 0; ลูกค้าเห็นเฉพาะงานตัวเอง; ledger/สลิป/รายงานเห็นเฉพาะของตัวเอง (แอดมินเห็นทั้งหมด)

## ก่อนขึ้นระบบจริง
- ใช้ HTTPS, เก็บไฟล์ใน object storage แทนการส่งรูปเป็น data URL, ตั้ง rate limit
- ต่อ payment gateway ที่ได้รับอนุญาต และตรวจสลิปอัตโนมัติ
- เปลี่ยนแผนที่เป็น Leaflet/Google Maps และส่งพิกัดจริงเข้า `/api/track`
- เปลี่ยน `/api/support` ให้เรียก Claude API ฝั่งเซิร์ฟเวอร์
- จัดการ PDPA (ตำแหน่ง, เอกสาร DBD) และให้ผู้เชี่ยวชาญตรวจเงื่อนไขเครดิต/คอมมิชชัน
- ตั้ง `DEMO_MODE=0` เพื่อปิดปุ่มจำลองคอมมิชชัน Affiliate (ของจริงต้องมาจาก webhook ที่ยืนยันการจ้างงาน)
- รหัสผ่านตัวอย่าง (`1234`, `admin`) ต้องเปลี่ยนก่อนใช้งานจริง

## หมายเหตุเวอร์ชัน
ฟีเจอร์ real-time ทั้งระบบ (`/api/stream`) และแชทติดต่อ/ร้องเรียนที่ทีมงานตอบผ่านหลังบ้าน (`support_messages`) ทำและทดสอบในเวอร์ชันพร้อมรัน `server-lite.js` แล้ว
ส่วนเวอร์ชัน Express + PostgreSQL (`server.js`) ยังไม่ได้พอร์ตสองส่วนนี้ (มีเฉพาะตารางใน `schema.sql`) ก่อนขึ้นระบบจริงต้องพอร์ตเพิ่ม

## ดีไซน์ v2 "แท็กช่าง"
- เทปเหลือง-ดำ (ป้ายงานก่อสร้าง) เป็นลายเซ็นของแบรนด์, ไอคอนบริการแบบสติกเกอร์ 6 หมวด, ใบงานแบบตั๋วมีรอยปรุ + แถบความคืบหน้า
- ลูกค้า (แนว Grab/Lineman): หน้าแรกฮีโร่ + ช่องบอกงาน, หมวดบริการ, แบนเนอร์, ช่างใกล้คุณ (เรียงช่างว่างและระยะทาง), ติดตามช่างพร้อมเวลาถึง, ปุ่มโพสต์กลางเมนูล่าง
- ช่าง (แนว Bolt): สวิตช์เปิด/พักรับงาน, ใบงานเรียงตามระยะทาง, เลื่อนเพื่อรับงาน, เครดิตนับเลขเคลื่อนไหว
- ลูกเล่น: confetti ตอนรับ/ปิดงาน, สั่นเบาๆ (vibrate) บนมือถือ, ปิดอนิเมชันอัตโนมัติถ้าเครื่องตั้งลดการเคลื่อนไหว

## หลังบ้าน: แท็บ "ผู้ใช้", แชท, โทร, แชร์โลเคชัน
- แท็บ **ผู้ใช้**: สถิติรวม (ผู้ใช้ทั้งหมด/ออนไลน์/สมัครใหม่ 7 วัน/ช่างยืนยัน DBD/เครดิตคงค้าง), กราฟผู้สมัครรายวัน, ค้นหา-กรอง-เรียง, การ์ดผู้ใช้พร้อมสถิติรายคน (ลูกค้า: โพสต์/ปิดงาน/จ่ายรวม, ช่าง: รับงาน/เสร็จ/รีวิว/เครดิต) และปุ่ม โทร / แชท / แผนที่ / รายละเอียด
- **แชท**: ใช้ช่องทางเดียวกับแชทติดต่อ/ร้องเรียนเดิม (AI ยังตอบแทน เมื่อไม่มีเจ้าหน้าที่ตอบใน 30 นาที)
- **โทร** (เสียงผ่านแอปด้วย WebRTC, ไม่เปิดเผยเบอร์): หลังบ้าน**โทรได้ครั้งละหนึ่งสายเท่านั้น** ผู้อื่นโทรซ้อนจะได้ข้อความ "สายหลังบ้านไม่ว่าง" ส่วนแชทและฟังก์ชันอื่นใช้พร้อมกันได้ปกติ ผู้ใช้โทรเข้าหลังบ้านไม่ได้ (ส่งข้อความแทน) โทรได้เฉพาะผู้ใช้ที่เปิดแอปอยู่ และทุกสายถูกบันทึกใน Data logger
- **แชร์โลเคชัน** (ทั้งสองฝั่ง): ส่งตำแหน่งปัจจุบัน / ตำแหน่งในโปรไฟล์ / วางลิงก์ Google Maps หรือพิกัด → ผู้รับเห็นการ์ดพร้อมปุ่ม Google Maps, นำทาง, Waze, แอปแผนที่ในเครื่อง (geo:), แชร์… (เมนูแชร์ของมือถือ: LINE/Messenger ฯลฯ) และคัดลอกลิงก์
- ข้อจำกัด: ไมโครโฟน/GPS ต้องใช้ **HTTPS หรือ localhost**; ถ้าเครือข่ายเข้มงวด (NAT/มือถือ 4G) ควรตั้ง TURN ผ่านตัวแปร `ICE_SERVERS` (JSON)
